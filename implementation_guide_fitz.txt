Implementation Guide
LogDLR++: LogLM-Enhanced Cross-System Log Anomaly Detection
Step-by-step implementation task
1. What You Have to Build
Implement an improved version of LogDLR. First reproduce the original LogDLR baseline. Then add the new 
components one by one. The final model uses LogLM, structure-preserving preprocessing, prototype-aware 
contrastive alignment, cosine + Huber reconstruction, and conformal calibration.

5. LogLM Resource
Official LogLM repository:
https://github.com/lunyiliu/LogLM

Important: do not start by full-fine-tuning LogLM. The first implementation should use a frozen LogLM

pipeline with SBERT as a temporary placeholder, then replace the representation module.

10. Step 4 - Structure-Preserving Preprocessing
The proposed preprocessing should retain useful operational information instead of deleting all non-alphabetic 
content.
Part
Example
Semantic text
connection failed on datanode
Parameters
IP=10.2.1.8, retry=8, port=50010
Structure
timestamp, sequence position, window index
Original:
ERROR Node 10.2.1.8 failed after 8 retries on port 50010
Proposed:
semantic = "error node failed after retries"
parameters = [10.2.1.8, 8, 50010]
structure = [timestamp, position, sequence_id]
11. Step 5 - Create Log Sequences
Start with the base-paper window size: w = 20.
WINDOW_SIZE = 20
for i in range(0, len(logs) - WINDOW_SIZE + 1):
    sequence = logs[i:i+WINDOW_SIZE]
Save sequence_id, domain, 20 log messages, and labels for evaluation only.
12. Step 6 - Extract LogLM Representations
For each log message, obtain a hidden representation from LogLM, then pool token states.
tokens = tokenizer(log_text, return_tensors="pt",
                     truncation=True)
outputs = loglm(**tokens, output_hidden_states=True)
hidden = outputs.hidden_states[-1]
mask = tokens["attention_mask"].unsqueeze(-1)
embedding = (hidden * mask).sum(dim=1) / mask.sum(dim=1)
Use a small projection layer so the LogLM representation matches the sequence encoder dimension.
self.projection = nn.Linear(loglm_dim, 384)
Cache embeddings to disk:

13. Step 7 - Build the Transformer Autoencoder
Use the same basic architecture as LogDLR, but feed LogLM vectors instead of SBERT vectors.
Input [batch, 20, embedding_dim]
        ↓
Transformer Encoder
        ↓
Latent representation Z
        ↓
Transformer Decoder
        ↓
Reconstructed sequence X_hat
During the LogLM comparison, keep the Transformer architecture unchanged so the comparison is fair.
14. Step 8 - Add DANN / GRL
The domain classifier predicts source or target. The Gradient Reversal Layer makes the encoder learn 
features that are less dependent on the system identity.
Z ───> reconstruction decoder
│
└──> GRL ───> domain classifier
              ├── source
              └── target
15. Step 9 - Build Normal Prototypes
A prototype is the center of a cluster of similar normal latent vectors.
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
cluster_id = kmeans.fit_predict(Z_normal)
prototypes = kmeans.cluster_centers_
Start with K=4. Later test K = 2, 3, 4, 5, 6.
16. Step 10 - Add Prototype Contrastive Alignment
similarity = cosine_similarity(z, prototypes)
positive = highest_similarity_prototype
L_proto =
    -log(
       exp(sim(z, positive)/tau) /
       sum_k exp(sim(z, prototype_k)/tau)
    )
Start with tau = 0.2 and gamma = 0.1.

17. Step 11 - Replace MSE with Cosine + Huber
L_cos = 1 - cosine_similarity(X, X_hat)
error = X - X_hat
L_huber =
    0.5 * error**2                  if |error| <= delta
    delta*(|error| - 0.5*delta)     otherwise
L_rec = lambda_cos * L_cos + (1 - lambda_cos) * L_huber
Start with lambda_cos = 0.5. Later test 0, 0.25, 0.5, 0.75, 1.0.
18. Step 12 - Final Training Loss
L_total =
    L_rec
    + beta * L_domain
    + gamma * L_proto
    + alpha * L_reg
Keep every term separate in code. This is required for ablation experiments.
19. Step 13 - Conformal Calibration
Use a held-out calibration set containing normal sequences.
p_value(x) =
    (1 + number of calibration scores >= score(x))
    / (n + 1)
if p_value < alpha:
    prediction = ANOMALY
else:
    prediction = NORMAL
Start with alpha = 0.05. Later test 0.01, 0.02, 0.05 and 0.10.
Do not use the final test set for calibration.

30. What Not to Do

Do not tune on the final test set.

Do not change the data split after seeing the result.

Do not report only the best source-target pair.

Do not claim LogLM is better without a controlled SBERT comparison.

Do not remove the original LogDLR baseline.

Do not full-fine-tune the 7B LogLM model as the first step.

Do not add all new losses at the same time.

Do not insert results that were not actually obtained.
